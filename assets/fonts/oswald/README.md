# Oswald v49 webfonts

These WOFF2 files are the exact Google Fonts Oswald v49 assets referenced by the archived Wfolio version of pavelkayler.com.

Source base URL: `https://fonts.gstatic.com/s/oswald/v49/`

They are vendored so the production site and future builds do not depend on Google Fonts at runtime or build time. Oswald is distributed under the SIL Open Font License 1.1; see `OFL.txt`.
